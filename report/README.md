# Lab report

Everything needed to write the FA504 lab reports in Quarto.

- [`quarto_guide/`](quarto_guide/): how to write a lab report in Quarto (figures, tables, equations, cross-references, citations with Zotero). Read this first.
- [`template/`](template/): the report template. Copy the whole folder for each new report.
- [`example_caco2/`](example_caco2/): a complete report built from the template with the Caco-2 data, showing what a finished report could look like.

Reports render to Word. The look of the Word file is controlled by `reference.docx`, and references are formatted with `vancouver.csl`. Keep both files next to the `.qmd`.
