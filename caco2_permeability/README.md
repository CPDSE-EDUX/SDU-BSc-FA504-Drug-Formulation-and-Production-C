# Exercise class: Caco-2 permeability

Problem-solving class (e-time) where students do their first data analysis in R. Students get a data set as an Excel file and work through the guide.

The data come from a Caco-2 transport study of a drug candidate X. Students calculate the cumulative amount transported (with correction for sampling), check sink conditions, find the steady-state flux and lag time by linear regression, and calculate the apparent permeability coefficient (P<sub>app</sub>).

The same workflow is reused in lab exercise 2.
